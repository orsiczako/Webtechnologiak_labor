JSON

A JavaScript Object Notation (JSON) egy könnyű, szövegalapú, programozási nyelvtől független adatformátum, amelyet adatok cseréjére használnak.

Specifikációk

  • ECMA-404: The JSON Data Interchange Syntax
  • RFC 8259: The JavaScript Object Notation (JSON) Data Interchange Format
  • ISO/IEC 21778:2017: Information technology—The JSON data interchange syntax

Példakód

                {
                    "title": "Batman Begins",
                    "year": 2005,
                    "rating": "PG-13",
                    "genres": ["action", "crime", "drama"]
                }

CSS

A Cascading Style Sheets (CSS) olyan nyelv, amely strukturált dokumentumok (például HTML- és XML-dokumentumok) megjelenítését írja le különböző megjelenítési környezetekben.

Specifikációk

  • A CSS-specifikációk teljes listája

Példakód

                h1, h2, h3, h4, h5, h6 {
                    text-align: center;
                }

                table.summary > tbody > tr:nth-child(odd) > td {
                    background-color: lightgray;
                }
